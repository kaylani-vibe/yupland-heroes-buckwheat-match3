# «Корона гречневого королевства» в Yupland Heroes

## Режимы сборки

- `npm run build` — одна сборка для самостоятельной игры и встраивания. При открытии напрямую сохраняются локальные баланс и рекорд. В окне родителя того же сайта игра получает партию и баланс через мост в `src/bridge.mjs`.
- `npm run build:site-demo` — демоверсия сайта. Вход без ставки, результаты не сохраняются. Если передан `session`, окно отправляет родителю `yupland:demo-ready` и `yupland:demo-close` с тем же идентификатором.

## Встраивание

- Родитель принимает вызовы `load`, `start`, `move`, `exit`, `rating` и сообщения `close`, `stats`. Стороны сверяют источник и адрес сообщений. Начатую партию можно продолжить из ответа `load`.
- Сервер рассчитывает баланс, результаты и выплату. Финальный экран показывает полную сумму `settlement.returned` в валюте входа. Вариант Darai отображается, только если его разрешает родитель.
- Серверная таблица гречи показывает сумму по всем партиям. Самостоятельная игра хранит в браузере рекорд за одну партию.
- Встроенная версия предварительно загружает игровые изображения и музыку. Музыка продолжает звучать между партиями.

Мост и типы для встраивания перенесены из патча Миши к коммиту `a5b70c3c14ad6f8384261f4bcc6c3627950585fc`. Правила в `src/engine.mjs` совпадают с версией в основной ветке на момент переноса.
