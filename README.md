# Корона гречневого королевства — Yupland Heroes

Отдельная браузерная мини-игра Match 3. В Yupland Heroes пока не подключена.

## Партия

- Постоянная карта 8 × 10 с неровным краем и неподвижными камнями.
- 25 ходов; ход тратится только на перестановку, которая создаёт совпадение.
- Короны появляются по одной и падают к выходу после удаления фишек. Три доставленные короны сразу завершают партию.
- Перестановка, исчезновение, падение и пополнение фишек анимированы. Четыре в ряд создают Луч, пять — Радугу, пересечение рядов — Вспышку; их срабатывание даёт вспышки и каскады.
- Вход: 100 золота. Возврат: 50 золота за доставленную корону. Итог = возврат − 100 золота.
- Совпадения дают гречу: 1 за каждую удалённую фишку, +2 за линию из четырёх, +5 за линию из пяти и длиннее, +2 × номер каскада после первого. Это **временные числа прототипа**; греча пока лишь результат партии, в игровой кошелёк не записывается.
- Перезапуск даёт ту же начальную раскладку и ту же карту. Для неё проверен путь к трём коронам за 15 ходов.

## Запуск

Нужны Node.js 22+ и npm. Выполнить `npm install`, затем `npm run dev`. Проверки: `npm test`, `npm run build`. `qa-mobile.html` показывает игру в рамке 360 × 740 px для визуальной проверки и не входит в игровую сборку.

Начальная основа поиска совпадений, перестановки, выбора стартовых фишек и вертикального падения адаптирована из [neo423/gem-blocks](https://github.com/neo423/gem-blocks), коммит `04bce8327830244798acf93976be86b4b1dfb890`, лицензия MIT (текст в `THIRD_PARTY_LICENSE.md`). После получения архива разработчика от 02.11.2026 правила Луча, Радуги и Вспышки адаптированы из его `src/shared/engine.ts`, а последовательность анимации — из `src/client/PlayBoard.tsx`. Сервер, база, магазин, изображения и фон исходной игры не переносились. Корона, камни, постоянная карта, расчёт золота и интерфейс созданы для этой версии. Иконки изготовлены отдельно по визуальному направлению Гречневого королевства.

## Ограничения

В прототипе нет авторизации, покупки за реальные игровые средства, продажи корон на рынке и начисления гречи на сервере. Экономический баланс 25 ходов требует игрового теста перед интеграцией. Визуал и числа бонусов требуют отдельной приёмки.
